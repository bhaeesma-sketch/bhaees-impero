## 2024-05-18 - Keyboard Navigation and Screen Reader Support on Icon Buttons\n**Learning:** Icon-only buttons (like menu, search, user dropdowns) in the layout lack context for screen readers and default focus states can be subtle or missing, hindering keyboard navigation.\n**Action:** Always add explicit `aria-label` attributes to icon-only buttons and utilize `focus-visible:ring-2 focus-visible:ring-primary focus-visible:outline-none` utility classes to ensure clear keyboard accessibility without compromising mouse/touch UX.

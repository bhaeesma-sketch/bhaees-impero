## 2025-06-07 - Add ARIA Labels to Interactive Elements
**Learning:** Icon-only buttons lacking `aria-label` attributes represent a recurring accessibility issue, preventing screen readers from conveying the button's purpose to users. In the header layout (`client/src/components/layout/header.tsx`), several critical interaction points (e.g., mobile menu toggle, search, user dropdown, close mobile menu, and theme toggle) were visually apparent but semantically opaque.
**Action:** Always ensure that icon-only interactive elements (like buttons) include a descriptive `aria-label` that clearly states their function or the resulting action, particularly for state-toggling elements (e.g., theme toggle should indicate "Switch to dark theme" or "Switch to light theme" dynamically).

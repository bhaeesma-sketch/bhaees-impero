## 2025-01-26 - Navigation Icon Buttons Accessibility Gap
**Learning:** Found an accessibility issue pattern specific to this app's components: icon-only buttons in the main application header (like Mobile Menu, Search, User Account, and Theme Toggle) were missing both ARIA labels and explicit visual focus indicators, making them invisible to screen readers and difficult to use for keyboard-only navigation.
**Action:** Always ensure icon-only buttons receive descriptive `aria-label` attributes and include robust explicit focus states (e.g., `focus-visible:ring-2 focus-visible:ring-primary`) when using Tailwind components that lack inherent visual focus indicators. Additionally, for state-toggling buttons like the Theme Toggle, dynamically set `aria-pressed` based on the current state to clearly report the action to screen readers.

## 2024-05-24 - Accessible Icon-Only Buttons and Radix UI
**Learning:** When using Radix UI's `asChild` prop (e.g., `<DropdownMenuTrigger asChild>`), adding accessibility attributes (`aria-label`, `focus-visible` classes) to the wrapper component does not reliably pass them down. They must be applied directly to the underlying child element (like a nested `<button>`) to ensure proper screen reader support and keyboard focus. Additionally, state-toggling buttons (like theme switches) need dynamic `aria-label`s based on their current state for maximum clarity.
**Action:** Always apply `aria-label` and explicit `focus-visible` styling directly to the native interactive elements (e.g., `<button>`) inside Radix UI `asChild` wrappers, and ensure state-toggles use conditional ARIA labels.

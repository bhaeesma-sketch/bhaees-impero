## 2024-06-20 - Header ARIA Labels
**Learning:** Added ARIA labels to icon-only buttons in the header for better accessibility. Also added `focus-visible:ring-2` to clearly highlight the elements during keyboard navigation. Dynamic state-based labels for theme toggle improves clarity over generic toggles.
**Action:** When adding labels to interactive elements, check if they change state and if they are fully keyboard accessible with visual cues.

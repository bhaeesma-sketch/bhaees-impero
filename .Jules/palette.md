## 2025-02-28 - Missing ARIA Labels and Focus Rings on Header Action Buttons
**Learning:** Icon-only action buttons in the main navigation header (search, user profile, theme toggle, and mobile menu close) lack descriptive ARIA labels, making their purpose ambiguous to screen reader users. Furthermore, they miss explicit keyboard focus indicators (`focus-visible:ring`), violating WCAG guidelines for focus visibility and keyboard accessibility.
**Action:** Enhance accessibility by adding contextually descriptive `aria-label` attributes to these icon-only buttons (e.g., dynamic labels for the theme toggle indicating 'Switch to dark theme' or 'Switch to light theme'). Concurrently, apply standard design system tailwind classes (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary`) to ensure robust keyboard navigation support without affecting mouse interactions.

## 2024-05-14 - Accessible Forms and Navigation
**Learning:** Found several icon-only buttons in the global header missing `aria-label` attributes, which prevents screen readers from understanding their purpose. Also, the auth forms lacked `required` attributes for native HTML validation and `autoComplete` attributes, making them less accessible and convenient for password managers.
**Action:** Added descriptive `aria-label`s to all icon buttons in the header (mobile menu, search, user account, close menu, theme toggle). Updated the authentication forms in `auth.tsx` and `AuthModal.tsx` to include `required` and correct `autoComplete` attributes (`username`, `current-password`, `new-password`). Also added an `onValueChange` to the Tabs in `auth.tsx` to clear shared state between Login and Register views to prevent state bleed, similar to AuthModal.

## 2024-05-15 - [Tabbed Form State Bleed and AutoComplete]
**Learning:** When using Radix UI `<Tabs>` for forms with shared state (e.g., Login/Register sharing `username`/`password` in `client/src/pages/auth.tsx`), state bleed occurs on tab switch. This can lead to confusing UX where a user partially fills out a login form, switches to register, and sees their login credentials populated. Furthermore, missing `autoComplete` attributes lead to poor password manager integration, especially for forms that change context (login vs registration).
**Action:** Always add an `onValueChange` handler to the `<Tabs>` component to explicitly clear the shared state when switching tabs. Apply this pattern to custom toggle buttons as well (e.g., in `client/src/components/auth/AuthModal.tsx`). Explicitly set `autoComplete="username"`, `autoComplete="current-password"`, and `autoComplete="new-password"` as appropriate to guide password managers correctly.

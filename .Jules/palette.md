## 2024-04-08 - Icon-Only Button Accessibility Pattern
**Learning:** Icon-only buttons (like the theme toggle, mobile menu toggle, search button, and user profile button) used across the site's header were missing explicit descriptive names for screen readers, meaning they would be completely silent or inaccurately announced. This is a common pattern for utility elements but critically impairs basic navigation and interaction for vision-impaired users relying on assistive tech. Additionally, visible focus states were lacking, hindering keyboard navigation.
**Action:** When implementing new utility icons or toggle buttons, universally apply `aria-label` providing clear, action-oriented descriptions (e.g. "Open Mobile Menu", "Switch to Dark Mode"). Accompany this with the established global keyboard focus classes (`focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary`) to ensure interactive status is clearly communicated both visually and via audio.

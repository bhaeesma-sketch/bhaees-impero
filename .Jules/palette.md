## 2024-06-13 - Header Navigation Focus States
**Learning:** Adding explicit keyboard focus states (`focus-visible:ring-2 focus-visible:ring-primary`) combined with `aria-label` tags to icon-only buttons in the global navigation bar improves non-mouse accessibility, particularly for state-toggling tools and interactive menus.
**Action:** Always ensure that structural UI components like layout headers or icon-only navigation buttons explicitly define accessible aria-labels and high-contrast focus rings when implementing them.
